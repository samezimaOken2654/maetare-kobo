# 前タレ工房

記者会見・セミナー・式典などで使う **前タレ(卓上の名前・肩書きプレート)** を作り、PDFで書き出すWebアプリです。

- サーバー不要。`index.html` をブラウザで開くだけで動きます
- 入力した名前・肩書きは**端末の外へ送信されません**
- 縦書きが既定。横書きにも切り替えられます
- 複数名をCSVから一括で読み込み、1つのPDFにまとめて出力できます

## 使い方

1. フォルダ内の `index.html` をブラウザで開きます(ダブルクリックで可)。
2. 左の「登壇者リスト」に、所属・肩書き・名前を入力します。複数名はCSVを読み込むと一括で入ります。
3. 中央のプレビューで仕上がりを確認し、右の「レイアウト設定」で調整します。
4. 「全員分をPDF出力」または「表示中の1枚をPDF出力」を押します。

プレビューの上下にある `‹` `›` で、登壇者ごとの仕上がりを順に確認できます。

## 主な機能

### 項目ごとの設定

所属・肩書き・名前のそれぞれについて、独立して次を変更できます。

| 設定 | 内容 |
|---|---|
| 表示 / 非表示 | 項目ごとにオン・オフ |
| 書字方向 | 縦書き(既定) / 横書き |
| フォント | 一覧から選択、または端末のフォントファイルを追加 |
| 文字サイズ | pt指定(スライダーまたは数値) |
| 太さ | 標準 / 太字 |
| 字間 | 文字サイズに対する割合(%) |
| 横位置・縦位置 | 用紙に対する割合(%) |
| 揃え | 中央 / 先頭を基準 / 末尾を基準 |

- 横位置は、縦書きでは「列の中心」、横書きでは揃えに応じた基準点を指します。
- 揃えの「先頭を基準」は、横書きでは左、縦書きでは上を意味します。「末尾を基準」は、横書きでは右、縦書きでは下です。
- プレビュー上の文字をドラッグして位置を動かせます(中央付近では吸着します)。タッチ端末では画面スクロールを優先するため、初期状態ではオフです。必要なら「プレビュー上でドラッグ移動」をオンにしてください。

### 用紙・全体

- 用紙サイズ: A2 / A3 / A4 / A5 / B3 / B4 / B5 / カスタム(mm指定)。初期値は **A3 縦**
- 向き: 縦 / 横
- 背景色・文字色、枠線(太さ・余白)
- はみ出す文字の自動縮小(既定でオン)
- 用紙を変えたとき、文字サイズを用紙の幅に比例して調整(既定でオン)

### 表示モード

既定はホワイトモードです。画面右上のボタンでダークモードに切り替えられます。選んだモードはこの端末のブラウザに記憶されます。

### CSV取り込み

「登壇者リスト」のエリアにCSVをドロップするか、「ファイルを選択」から読み込みます。「サンプルCSV」ボタンで見本をダウンロードできます。

```csv
名前,肩書き,所属
山田 太郎,代表取締役社長,株式会社サンプル
佐藤 花子,取締役 最高技術責任者,株式会社サンプル
```

- **見出し行あり**: 1行目に次のいずれかの見出しがあれば、自動で列を振り分けます。
  - 名前: `名前` `氏名` `お名前` `登壇者` `name`
  - 肩書き: `肩書き` `肩書` `役職` `職名` `職位` `title` `position`
  - 所属: `所属` `組織` `団体` `会社` `会社名` `機関` `所属先` `org` `organization` `company`
- **見出し行なし**: 1列目を名前、2列目を肩書き、3列目を所属として読み込みます。
- 区切りはカンマまたはタブ。ダブルクォートで囲んだセルにも対応します。
- 文字コードは UTF-8 と Shift_JIS(Excelの既定)を自動判定します。
- すでに入力済みのリストがある場合は、「置き換える」か「末尾に追加する」かを選べます。

### PDF出力

- 全員分を1つのPDFにまとめて出力できます。1人1ページです。
- 解像度は 150 / 200(既定) / 300 dpi から選べます。
- 名前・肩書き・所属がすべて空の行は出力されません。
- ファイル名は `maetare-日付-時刻.pdf` になります。

## プライバシーと保存

- 画像・PDFの生成はすべてブラウザ内で行います。`index.html` には、外部通信(fetch / XHR / WebSocket)を禁止する設定を入れています。
- レイアウト設定と表示モードは、この端末のブラウザ(localStorage)にだけ保存されます。
- 登壇者リスト(名前など)は、既定では保存されません。「フォント・出力」の設定で「登壇者リストもこの端末に保存する」をオンにした場合のみ保存されます。共用のパソコンではオンにしないでください。
- 保存データは、設定パネル下部の「設定を初期化して保存データを削除」で消せます。

## フォントについて

標準のフォント一覧は、端末にインストールされているフォントを使います(ゴシック、明朝、BIZ UDゴシック、BIZ UD明朝、丸ゴシック、メイリオ、教科書体、欧文)。指定のフォントが端末にない場合は、近い書体に置き換わります。**別のパソコンで開くと見た目が変わることがあります。** 本番に使うパソコンで、一度プレビューを確認してください。

特定のフォントで確実に出したい場合は、「フォント・出力」から `.ttf` `.otf` `.woff` `.woff2` のファイルを追加してください。ファイルは端末内で読み込まれるだけで、アップロードされません。ページを開き直すと、再度の追加が必要です。ライセンス上、再配布や用途が制限されているフォントがあるので、利用条件を確認してください。

## 既知の制限

- PDFは、ページ全体を1枚の画像(JPEG)として埋め込む方式です。文字の検索やコピーはできません。印刷用途では問題ありません。
- 用紙が大きく解像度が高いと、ブラウザの画像サイズ上限(約1,600万画素)を超えます。その場合は解像度を自動で下げ、画面にお知らせを表示します。
- 縦書きでは、長音「ー」や括弧を回転して表示し、句読点と小さい仮名の位置を補正しています。ただし、「」『』は縦書き専用の字形にはなりません。
- 各項目は1行です。複数行の肩書きや、人ごとの個別レイアウト調整には対応していません。レイアウトは全員共通です。
- 最新の Chrome / Edge / Safari / Firefox での利用を想定しています。

## ファイル構成

```
maetare-kobo/
├─ index.html   画面の骨組み
├─ style.css    デザイン(ホワイト / ダークモード)
├─ app.js       状態管理、画面操作、プレビュー、CSV取り込み、PDF出力の制御
├─ renderer.js  前タレ1枚の描画(縦書き・横書き、自動縮小)と、用紙・フォント定義
├─ csv.js       CSVの文字コード判定・パース・見出し判定
├─ pdf.js       外部ライブラリなしのPDF組み立て
└─ README.md    このファイル
```

外部のライブラリやCDNは使っていません。スクリプトは通常の `<script>` 読み込みなので、ローカルで開いても動きます。

## カスタマイズ

| 変えたいこと | 場所 |
|---|---|
| 初期の位置・文字サイズ・フォント・用紙 | `app.js` の `defaults()` |
| 初期表示のサンプル登壇者 | `app.js` の `sampleSlips()` |
| 用紙サイズの追加 | `renderer.js` の `PAPERS`(幅×高さをmmで、短辺・長辺の順) |
| フォント候補の追加・変更 | `renderer.js` の `BUILTIN_FONTS` |
| CSVの見出し名の追加 | `csv.js` の `ALIASES` |
| 配色 | `style.css` 先頭の色の変数 |

初期値を変えた後は、ブラウザに保存された古い設定が優先されることがあります。その場合は「設定を初期化して保存データを削除」を押してください。開発者が配布する場合は、`app.js` の `STORE_KEY` の末尾(`v3`)を上げると、既存の保存データを無効にできます。
